# sp6-2_smart-table_starter

**Репозиторий:** [github.com/ZakharovVlr/smart-table](https://github.com/ZakharovVlr/smart-table)

Интерактивная таблица данных о продажах с постраничной навигацией, сортировкой, фильтрацией и поиском. Учебный проект курса Яндекс Практикум «Фронтенд-разработчик Плюс», реализован на чистом JavaScript и Vite.

## Функциональность

- **Вывод данных** — рендер строк таблицы из HTML `<template>` через клонирование
- **Пагинация** — постраничный вывод с настраиваемым количеством строк на странице
- **Сортировка** — по дате и сумме покупки, с переключением направления по клику
- **Фильтрация** — по покупателю, продавцу, дате, диапазону суммы
- **Поиск** — полнотекстовый поиск сразу по нескольким полям

## Архитектура

Проект построен на едином пайплайне обработки данных:
Исходные данные → Поиск → Фильтрация → Сортировка → Пагинация → Вывод в таблицу
